# Firewall

Локальный фаервол для Android 10 и новее.

## Возможности версии 0.1.1

- На вкладке «Управление» отображается статус фаервола и настраивается показ системных программ.
- На вкладке «Программы» можно найти установленный пакет, задать правила для Wi-Fi и мобильной сети, включить исключение и увидеть цветовую индикацию.
- Правила сохраняются на устройстве. Для новых приложений обе сети изначально имеют состояние «Не активен».

## Применение правил через VPN

Правила решения о доступе реализованы и проверяются тестами JVM. Подключение VPN-сервиса, блокировка трафика, уведомления и исключение для FTP ещё в разработке. В версии 0.1.1 кнопка «Включить» недоступна.

| Правило текущей сети | Действие после подключения VPN |
| --- | --- |
| Не активен | Блокируется попытка подключения. Уведомление предлагает разрешить или запретить доступ для этого приложения и этой сети |
| Разрешено | Доступ разрешён без уведомления |
| Запрещено | Доступ заблокирован без уведомления |

Изначально оба правила не заданы. Это также относится к приложениям, установленным после первого запуска. Выбор из уведомления сохраняется для соответствующей сети. Полное исключение приложения даёт прямой доступ к сети.

После первоначального разрешения VPN фаервол должен восстанавливать работу после перезагрузки. Для домашнего Wi-Fi настройки FTP задают имя сети, IPv4-подсеть клиентов и TCP-порты сервера «Проводника» на телефоне. Исключение действует только для FTP и только в выбранной сети. Совместимость входящих подключений и передачи данных под VPN нужно проверить на устройстве до выбора реализации.

## Сборка приложения и проверка правил

Требуются JDK 21 и Android SDK 36.

```sh
./gradlew :policy:test :app:lintDebug
```

### Подпись APK

Сборки для установки подписываются ключом от `Firewall_0.1.0_debug.apk`.
Его сертификат закреплён в `app/build.gradle.kts`. Gradle останавливает упаковку
APK, если закрытый ключ недоступен или сертификат отличается.

Перед сборкой задай переменные окружения в своей среде сборки.

| Переменная | Значение |
| --- | --- |
| `FIREWALL_SIGNING_STORE_FILE` | Абсолютный путь к исходному хранилищу ключа JKS или PKCS#12 |
| `FIREWALL_SIGNING_STORE_PASSWORD` | Пароль хранилища |
| `FIREWALL_SIGNING_KEY_ALIAS` | Имя ключа в хранилище |
| `FIREWALL_SIGNING_KEY_PASSWORD` | Пароль ключа |

Храни закрытый ключ и его защищённую резервную копию вне Git. В среде CI
передавай пароль и ключ через хранилище секретов.

```sh
./gradlew :app:verifyFirewallSigning :app:assembleDebug
apksigner verify --print-certs app/build/outputs/apk/debug/app-debug.apk
```

Перед публикацией сравни строку `Signer #1 certificate SHA-256 digest` с
`expectedCertificateSha256` в `app/build.gradle.kts`.
