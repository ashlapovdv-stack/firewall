# Firewall

Локальный фаервол для Android 10 и новее.

## Возможности 0.2.0

- «Управление» запрашивает системное разрешение VPN, показывает состояние сервиса и включает или выключает его. Системные приложения можно скрыть из списка.
- «Программы» показывает установленные пакеты. Правила Wi-Fi и мобильной сети и отметка исключения сохраняются на устройстве.
- Локальный VPN обрабатывает TCP и UDP по IPv4 и IPv6. Исходящие соединения идут через текущую сеть телефона. Приложение не использует удалённый VPN-сервер и не сохраняет содержимое трафика.
- VPN пересматривает правила и завершает старые соединения при смене сети или правил. При смене сети новые подключения оцениваются по её правилам.
- VPN запоминает включённое состояние. После перезагрузки пытается восстановиться при сохранённом разрешении VPN. Для запуска под управлением Android можно выбрать «Постоянный VPN» в системных настройках.

| Правило текущей сети | Действие VPN |
| --- | --- |
| Не активен | Соединение блокируется. При разрешённых уведомлениях можно разрешить или запретить доступ для конкретной программы и сети |
| Разрешено | Трафик TCP/UDP проходит без уведомления |
| Запрещено | Трафик блокируется без уведомления |

Исключения Android применяет по UID. Если несколько приложений используют один UID,
прямой выход возможен при исключении всех приложений этой группы. Системная
настройка «Блокировать подключения без VPN» запрещает прямой выход для исключений.

### Домашний FTP

Автоматическое исключение входящего FTP для стороннего «Проводника» ещё не
реализовано. Android VPN получает пакеты, направленные системой в виртуальный
интерфейс, и не управляет входящими соединениями к сокету другого приложения.
Исключение маршрутов по IP затронуло бы все порты выбранной сети. Для FTP нужен
отдельный способ организации входящего подключения с проверкой передачи файла.

## Сборка приложения и проверка правил

Требуются JDK 21, Android SDK 36, Android NDK 28.1.13356709 и Go 1.23.1 или новее.
Библиотека VPN собирается для Android arm64 и x86-64. Если NDK установлен вне
Android SDK или Go недоступен в `PATH`, задайте `FIREWALL_NDK_HOME` или
`FIREWALL_GO` соответственно. Библиотеки и лицензии указаны в `vpn-engine/go.mod`
и `app/src/main/assets/licenses`.

```sh
./gradlew :policy:test :app:lintDebug :app:buildFirewallEngine
(cd vpn-engine && go test ./...)
```

### Подпись APK

Сборки для установки подписываются ключом от `Firewall_0.1.0_debug.apk`.
Его сертификат закреплён в `app/build.gradle.kts`. Gradle останавливает упаковку
APK, если закрытый ключ недоступен или сертификат отличается.

Перед сборкой задай переменные окружения в своей среде сборки.

| Переменная | Значение |
| --- | --- |
| `FIREWALL_SIGNING_STORE_FILE` | Абсолютный путь к исходному хранилищу ключа JKS или PKCS#12 |
| `FIREWALL_SIGNING_STORE_PASSWORD` | Пароль хранилища |
| `FIREWALL_SIGNING_KEY_ALIAS` | Имя ключа в хранилище |
| `FIREWALL_SIGNING_KEY_PASSWORD` | Пароль ключа |

Храни закрытый ключ и его защищённую резервную копию вне Git. В среде CI
передавай пароль и ключ через хранилище секретов.

```sh
./gradlew :app:verifyFirewallSigning :app:assembleDebug
apksigner verify --print-certs app/build/outputs/apk/debug/app-debug.apk
```

Перед публикацией сравни строку `Signer #1 certificate SHA-256 digest` с
`expectedCertificateSha256` в `app/build.gradle.kts`.
