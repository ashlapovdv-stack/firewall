# Firewall

Локальный фаервол для Android 10 и новее. Репозиторий содержит модуль принятия решений о сетевом доступе. Android-приложение и VPN-сервис ещё предстоит подключить.

## Правила доступа в первой версии

В списке приложений у каждого есть отдельное правило для Wi-Fi, правило для мобильной сети и переключатель «Исключить из фаервола».

| Правило текущей сети | Результат |
| --- | --- |
| Не активен | Блокируется попытка подключения. Уведомление предлагает разрешить или запретить доступ для этого приложения и этой сети |
| Разрешено | Доступ разрешён без уведомления |
| Запрещено | Доступ заблокирован без уведомления |

Изначально оба правила не заданы. Это также относится к приложениям, установленным после первого запуска. Выбор из уведомления сохраняется для соответствующей сети. Полное исключение приложения даёт прямой доступ к сети.

После первоначального разрешения VPN фаервол должен восстанавливать работу после перезагрузки. Для домашнего Wi-Fi настройки FTP задают имя сети, IPv4-подсеть клиентов и TCP-порты сервера «Проводника» на телефоне. Исключение действует только для FTP и только в выбранной сети. Совместимость входящих подключений и передачи данных под VPN нужно проверить на устройстве до выбора реализации.

## Проверка модуля правил

Требуется JDK 21.

```sh
./gradlew :policy:test
```
